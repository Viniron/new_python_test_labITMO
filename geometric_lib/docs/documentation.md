# Документация библиотеки geometric_lib(Написано с использованием ИИ)

## Общее описание решения

geometric_lib — небольшая библиотека на Python для вычисления площади и периметра
плоских геометрических фигур. Каждая фигура вынесена в отдельный модуль, внутри
модуля всегда две функции: `area` — площадь, `perimeter` — периметр.

Структура проекта:

```
geometric_lib
 ├── circle.py       круг
 ├── square.py       квадрат
 ├── rectangle.py    прямоугольник
 ├── triangle.py     треугольник
 └── docs
     ├── README.md         справочник формул
     └── documentation.md  этот файл
```

Никаких сторонних зависимостей нет, используется только модуль `math` из
стандартной библиотеки. Чтобы работать с библиотекой, достаточно импортировать
нужный модуль:

```python
import rectangle

print(rectangle.area(4, 5)) 
print(rectangle.perimeter(4, 5)) 
```

Формулы, по которым ведутся вычисления:

| Фигура         | Площадь    | Периметр  |
|----------------|------------|-----------|
| Круг           | S = пиR^2  | P = 2пиR  |
| Квадрат        | S = a^2    | P = 4a    |
| Прямоугольник  | S = ab     | P = 2(a+b)|
| Треугольник    | S = ah/2   | P = a+b+c |

Те же формулы в исходном виде лежат в файле `README.md` этого же каталога.

## Описание функций

### circle.py

**area(r)**

Считает площадь круга по его радиусу.

- `r` (float) — радиус круга.
- Возвращает: float, площадь круга.

```python
import circle

circle.area(3)
```

**perimeter(r)**

Считает длину окружности по её радиусу.

- `r` (float) — радиус окружности.
- Возвращает: float, длина окружности.

```python
import circle

circle.perimeter(5)
```

### square.py

**area(a)**

Считает площадь квадрата по длине его стороны.

- `a` (float) — длина стороны квадрата.
- Возвращает: float, площадь квадрата.

```python
import square

square.area(3) 
```

**perimeter(a)**

Считает периметр квадрата по длине его стороны.

- `a` (float) — длина стороны квадрата.
- Возвращает: float, периметр квадрата.

```python
import square

square.perimeter(3) 
```

### rectangle.py

**area(a, b)**

Считает площадь прямоугольника по двум его сторонам.

- `a` (float) — длина первой стороны;
- `b` (float) — длина второй стороны.
- Возвращает: float, площадь прямоугольника.

```python
import rectangle

rectangle.area(4, 5) 
```

**perimeter(a, b)**

Считает периметр прямоугольника по двум его сторонам.

- `a` (float) — длина первой стороны;
- `b` (float) — длина второй стороны.
- Возвращает: float, периметр прямоугольника.

```python
import rectangle

rectangle.perimeter(4, 5)
```

### triangle.py

**area(a, h)**

Считает площадь треугольника по стороне и высоте, проведённой к ней.

- `a` (float) — длина стороны треугольника;
- `h` (float) — длина высоты, опущенной на сторону a.
- Возвращает: float, площадь треугольника.

```python
import triangle

triangle.area(6, 4) 
```

**perimeter(a, b, c)**

Считает периметр треугольника по трём его сторонам.

- `a` (float) — длина первой стороны;
- `b` (float) — длина второй стороны;
- `c` (float) — длина третьей стороны.
- Возвращает: float, периметр треугольника.

```python
import triangle

triangle.perimeter(3, 4, 5) 
```
